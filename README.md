# DiT Research Lab

Diffusion Transformer의 내부 표현과 생성 과정을 분석하는 연구 프로젝트입니다.

## Research Questions

- DiT의 layer별 역할은 어떻게 다른가?
- 의미 정보는 어느 timestep에서 형성되는가?
- attention head마다 기능적 전문화가 존재하는가?
- attention과 실제 인과적 영향은 얼마나 일치하는가?

## Structure

- `src/`: 핵심 분석 코드
- `scripts/`: 실험 실행 스크립트
- `configs/`: 실험 설정
- `notebooks/`: 분석 노트북
